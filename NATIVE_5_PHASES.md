# Native Android — 5 phases (Jetpack Compose)

| Phase | Scope |
|-------|--------|
| **1** ✅ | Remove website deploy; API-only server; endpoint contract for Compose |
| **2** | Kotlin/Compose project scaffold, design system (theme, colors, type), navigation |
| **3** | Auth + profile + wallet screens wired to API |

| **5** | Polish, release signing, Play-ready APK |

**Stack (required):** Kotlin · Jetpack Compose · Android SDK · Android Studio
